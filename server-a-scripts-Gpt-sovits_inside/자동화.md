# GPT-SoVITS Server A 완전 자동화 가이드

이 문서는 **Server A**(`/opt/GPT-SoVITS`)에서 구동되는 **두 가지 핵심 API**와 이를 관리하는 **자동화 시스템**에 대해 설명합니다.

---

## 1. 구성 요소 (Components)

### A. 학습용 API (`training_api.py`)

- **Port**: `10002`
- **역할**: 오디오 전처리, 학습, 모델 생성을 오케스트레이션.
- **주요 기능**:
  - `POST /api/train/start`: 학습 파이프라인 시작 (Slicing -> ASR -> Train).
  - `GET /api/train/status/{model_id}`: 실시간 진행률 확인.
  - `GET /api/train/log/{model_id}`: 상세 로그(`pipeline.log`) 조회.

### B. 파일 스캔 API (`file_scanner_api.py`)

- **Port**: `10001`
- **역할**: 서버 내의 모델 파일(`.pth`, `.ckpt`)과 오디오 파일을 스캔하여 백엔드에 제공.
- **주요 기능**:
  - `GET /files`: 지정된 경로의 파일 목록 반환.

### C. 서비스 관리자 (`service_manager.sh`)

- **역할**: 위 두 API를 `systemd` 서비스로 등록하고 관리하는 스크립트.
- **서비스 파일**:
  - `gpt-sovits-files.service` (Scanner)
  - `gpt-sovits-training.service` (Training)

---

## 2. 설치 및 실행 (Installation & Run)

복잡한 명령어 없이 `service_manager.sh` 스크립트 하나로 모든 관리가 가능합니다.

### 1단계: 파일 배포

다음 파일들을 Server A의 `/opt/GPT-SoVITS/` 경로에 위치시킵니다.

- `training_api.py`
- `file_scanner_api.py`
- `gpt-sovits-files.service`
- `gpt-sovits-training.service`
- `service_manager.sh`

### 2단계: 설치 (Root 권한 필요)

```bash
cd /opt/GPT-SoVITS
chmod +x service_manager.sh
./service_manager.sh install
```

> **자동 수행 작업**:
>
> 1. 서비스 파일들을 `/etc/systemd/system/`으로 복사.
> 2. `systemctl daemon-reload` 실행.
> 3. 부팅 시 자동 실행(`enable`) 설정.

### 3단계: 실행 및 관리

```bash
# 서비스 시작
./service_manager.sh start

# 서비스 중지
./service_manager.sh stop

# 서비스 재시작
./service_manager.sh restart

# 상태 확인
./service_manager.sh status

# 실시간 로그 확인 (Ctrl+C로 종료)
./service_manager.sh logs
```

## 3. 학습 파이프라인 상세 (Training Pipeline)

`training_api.py`가 수행하는 자동 학습 과정은 다음과 같습니다.

### **Step 1: 오디오 자르기 (Slicing)**

- **Tool**: `tools/slice_audio.py`
- **설정**: Threshold `-34`dB, Min Length `4000`ms, Hop Size `10`.

### **Step 2: 음성 인식 (ASR)**

- **Tool**: `tools/asr/fasterwhisper_asr.py`
- **모델**: `large-v3-turbo` (Float32, Auto Language).
- **결과**: `sliced.list` 생성.

### **Step 3: 데이터 전처리 (Formatting)**

- 텍스트 토큰화 (`1-get-text.py`)
- SSL 특징 추출 (`2-get-hubert.py`)
- 의미 토큰 추출 (`3-get-semantic.py`)

### **Step 4: SoVITS & GPT 학습**

- **SoVITS**: `s2_train.py` (Epoch 8, Batch 11, Save Freq 4)
- **GPT**: `s1_train.py` (Epoch 15, Batch 11, Save Freq 5)

## 4. 버전별 모델 매핑 (Version Support)

API는 요청받은 `version` 파라미터에 따라 자동으로 적절한 Pretrained Model을 로드합니다.

| 버전          | GPT 모델 (s1)                | SoVITS 모델 (s2)             | Config             |
| :------------ | :--------------------------- | :--------------------------- | :----------------- |
| **v1**        | `s1bert25hz-2kh-longer...`   | `s2G488k.pth`                | `s2.json`          |
| **v2**        | `gsv-v2final-pretrained/...` | `gsv-v2final-pretrained/...` | `s2.json`          |
| **v4**        | `s1v3.ckpt`                  | `gsv-v4-pretrained/...`      | `s2.json`          |
| **v2Pro**     | `s1v3.ckpt`                  | `v2Pro/s2Gv2Pro.pth`         | `s2v2Pro.json`     |
| **v2ProPlus** | `s1v3.ckpt`                  | `v2Pro/s2Gv2ProPlus.pth`     | `s2v2ProPlus.json` |

## 5. API 명세 (API Specification)

### **학습 시작**

- **URL**: `POST /api/train/start`
- **Body**:
  ```json
  {
    "model_name": "my_voice_01",
    "upload_path": "/opt/GPT-SoVITS/ref_audio/my_dir",
    "version": "v2Pro",
    "batch_size": 11,
    "dry_run": false
  }
  ```

### **상태 조회**

- **URL**: `GET /api/train/status/{model_name}`
- **Response**: `{"status": "processing", "progress": 0.5, "message": "..."}`

### **로그 조회 (New)**

- **URL**: `GET /api/train/log/{model_name}`
- **Response**: `{"log": "[2024-01-27 12:00] Starting..."}`
