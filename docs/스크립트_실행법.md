## 문제 해결

### 문제 1: "Permission denied" 오류

```bash
# 실행 권한 부여
chmod +x scripts/server-a/*.sh
chmod +x scripts/server-b/*.sh

# 또는 직접 bash로 실행 (권장)
bash scripts/server-a/setup-services.sh
```

### 문제 2: "No such file or directory" 오류

```bash
# 현재 디렉터리 확인
pwd

# 스크립트 파일 존재 확인
ls -la scripts/server-a/

# 절대 경로로 실행
bash /path/to/madcamp-Screening-Humanity-AI-Server/scripts/server-a/setup-services.sh
```

### 문제 3: Windows 줄바꿈 문제 (`$'\r': command not found` 오류)

이 오류는 Windows에서 생성된 파일의 CRLF 줄바꿈 때문입니다.

**해결 방법 1: sed로 변환 (가장 간단)**
```bash
# 모든 스크립트 파일 변환
sed -i 's/\r$//' scripts/server-a/*.sh
sed -i 's/\r$//' scripts/server-b/*.sh
```

**해결 방법 2: dos2unix 사용**
```bash
# dos2unix 설치 (없다면)
sudo apt-get install -y dos2unix

# 변환
dos2unix scripts/server-a/*.sh
dos2unix scripts/server-b/*.sh
```

**해결 방법 3: Git 설정으로 자동 변환**
```bash
# .gitattributes 파일 생성 (프로젝트 루트에)
echo "* text=auto" > .gitattributes
echo "*.sh text eol=lf" >> .gitattributes

# 기존 파일 변환
git add --renormalize .
```

**참고**: 스크립트 파일들은 이미 Unix 형식(LF)으로 저장되어 있어야 하지만, Windows에서 편집하면 다시 CRLF로 변환될 수 있습니다.

### 문제 4: nvidia-smi 오류

**증상**: `nvidia-smi: command not found` 또는 GPU 정보가 표시되지 않음

**원인**:
- NVIDIA 드라이버가 설치되지 않음
- GPU가 인식되지 않음
- Server A가 GPU 서버가 아님

**해결**:
- Server A는 반드시 NVIDIA GPU가 있어야 합니다
- NVIDIA 드라이버를 설치하거나 GPU를 확인하세요
- GPU가 없으면 Server A를 GPU 서버로 사용할 수 없습니다
